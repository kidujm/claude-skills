# 쓰레드 카드 체크리스트

수정 요청이 반복된 항목을 모은 목록. 시안을 보여 주기 전에 전부 확인한다.

## 주제와 예시
- 첫 장에 주제가 바로 보이게, 보는 사람의 고민을 질문으로
- "왜 이렇게 만드나, 보는 손님은 뭘 걱정하나"까지 생각해서 구성
- 예시는 실제 웹 화면(사람 얼굴 나오는 곳 제외). 개인 블로그 글은 예시로 쓰지 않음
- 저작권이 걱정되면 실제 사이트 캡처 대신 가상 가게 화면을 HTML로 직접 그려 찍기(사진은 직접 생성, 아이콘은 직접 SVG, 글꼴은 OFL)

## 말투
- 명령형 "~하세요" 금지, 정보 주는 느낌
- 굵은 줄은 명사로 끊기("사진 한 장이 답")
- 물결표·"~에요" 금지, 본문만 반말 질문
- 마지막 장은 자사 서비스 맥락으로, "AI에게는" 같은 막연한 주어 금지
- 초보 독자 대상이면 업계 용어 대신 누구나 아는 말

## 색
- 흰 바탕, 강조는 굵기만
- 틀 연회색 #F2F3F5, 회색 글자 #8B9097
- 포인트색은 요청할 때만 핵심 단어 하나에

## 레이아웃
- 좌우 여백 104px, 제목 68~72px, 이미지 틀 872x820
- 제목·이미지 틀·로고 위치는 전 장 고정해 한 세트로 보이게
- 사진 밝기·채도는 코드로 전 장 동일하게 맞춤

## 화면 사진
- 회색 틀 없이 화면 사진만 흰 바탕에, 모서리 12px
- 흰 바탕 사이트 화면은 카드와 구분이 안 되므로 브라우저 창 모양(연회색 위 막대 + 흰 주소 칸, 옅은 그림자, 신호등 점 금지)에 넣기
- 굵은 외곽선·얼굴 캐릭터 같은 귀여운 일러스트로 바꾸지 않기
- 피드에서 작게 안 보이게 답하는 부분 주변을 확대
- 강조는 주변을 어둡게만, 흰 테두리·외곽선 금지
- 출처는 화면 바로 아래 18px 회색, 화면 아래 부연 설명 한 줄 넣지 않기

## 첫 장
- 예시 화면을 카드 전체에 깔고 흰색으로 덮어 흐리게(제목 쪽은 거의 흰색), 사이트 메뉴 글자가 제목과 겹치지 않게 헤더는 잘라냄
- 사진을 깔 땐 주제와 맞는 색 진한 실제 장면. 기본값처럼 빵·꽃 사진 고르지 않기

## 배경 사진
- 흰 바탕 기본, 분위기가 필요한 장만 그 장 문구 내용을 찍은 장면을 흐려서(1080폭 기준 blur 12px)
- 선명한 AI 생성 사진, 사람 얼굴과 손, 사진 속 글자 금지
