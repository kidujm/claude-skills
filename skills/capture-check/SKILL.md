# capture-check

필요: Python, `pip install playwright pillow`, `playwright install chromium`

## 1. 캡처
```bash
python ~/.claude/skills/capture-check/shoot.py <URL 또는 html 경로> <출력 폴더> [--widths 1440,390,360] [--wait 1500]
```
- 출력 폴더: 사용자에게 줄 캡처면 작업 폴더 아래 `캡처_<YYYYMMDD>/`, 내 점검용이면 임시 폴더.
- 결과: 폭별 전체 화면 png + `_비교.png`(폭별 나란히). 가로 넘침은 스크립트가 숫자로 출력한다.
- 로그인이 필요한 화면은 이 스크립트로 못 찍는다. 사용자 브라우저를 조작하는 도구로 찍는다.
- 인물 사진이 있는 사이트를 SNS용으로 찍으면 얼굴이 특정되지 않게 흐린다.

## 2. 점검
`_비교.png`와 폭별 png를 직접 열어 섹션 단위로 본다.
- 가로 넘침, 글자 잘림, 사진 위 글씨 대비
- 모바일에서 혼자 남는 카드 한 개, 섹션 사이 큰 빈칸, 떠 있는 버튼이 내용 가림
- 웹폰트가 대체 글꼴로 나오지 않는지(폰트는 @font-face로 직접 로드해야 모든 기기에서 같게 보임)
- 슬롭 패턴(slop-check 스킬 5번 디자인 검사)

## 3. 고치고 다시 찍기
- 내가 만든 페이지면 고친 뒤 1번부터 다시. 문제 0건이 될 때 보고한다.
- 남의 사이트·운영 중인 사이트는 고치지 않고 문제 목록만 보고한다.

## 4. 보고
- 비교 이미지 경로와 폭별 문제 목록(없으면 "문제 없음")만.
