# AI 슬롭 판정 목록

AI 슬롭: 사람의 판단 없이 그럴듯하게만 찍어낸 결과물. 문장은 매끄러운데 읽고 나면 경험·관점·근거가 남지 않는 것.

판정 원칙
- 패턴 하나로 단정하지 않는다. 여러 개가 겹칠수록 티가 난다.
- 겉 패턴만 지우고 끝내지 않는다. 일반론 대신 구체적 사실·숫자·장면·출처가 있는지 본다. 없는 근거는 지어내지 않는다.
- 애매하면 더 담백한 쪽을 고른다.

## 글
- **구두점·기호**: 엠대시 0개(콜론·쉼표·괄호로 대체). 본문에 화살표·≈·체크 같은 특수 기호, 장식용 이모지 넣지 않기
- **구조 버릇**: "A가 아니라 B", "단순한 A를 넘어 B" 반전 구문 / 습관적 3개 묶음 / "핵심은 이겁니다" 식 예고 후 말하기 / 단락·글 끝 요약 반복 / "과제와 전망" 식 공식 마무리
- **부풀리기**: "~의 증거", "새 장을 열다", "빠르게 변화하는 시대에" 같은 의미 과장 / 브로셔 말투("~를 자랑하는", "~의 중심에 자리한") / 출처 없는 "전문가들은 ~" / 문장 끝 "~에 기여하며", "~를 보여주며" 꼬리절
- **단골 어휘**: delve, tapestry, pivotal, landscape, testament, seamless, robust, leverage, serves as / "핵심적인", "획기적인", "다양한", "~하는 것이 중요합니다", "~라고 할 수 있습니다", "살펴보겠습니다", "~로 자리매김"
- **번역투**: "~되어지다", "~에 의해", "~를 통해", "~함에 있어", 무생물 주어, "또한·더불어·나아가" 남발, 문장 길이가 전부 같은 리듬
- **기교**: 숫자 한 줄 끊어치기 오프닝, 비유·수사, 개수 자랑
- **챗봇 잔재**: "물론이죠", "좋은 질문이에요", "도움이 되셨길 바랍니다", "궁금한 점 있으면"
- **형식 과잉**: 볼드 남발, 한 문장이면 될 내용을 불릿으로 쪼개기, 제목에 이모지

## 디자인·이미지·영상
- 보라·파랑 그라디언트 배경, 글씨 그라디언트, 파스텔 그라디언트 블록
- 제목 위 알약형 칩·작은 머리글·"01/02/03" 단계 번호, 색 점·컬러칩·색 테두리로 항목 구분
- 똑같은 카드 3개 가로 나열, 전부 카드에 담기, 전부 가운데 정렬
- 모든 요소에 같은 큰 둥근 모서리, 카드마다 glow 그림자, 글래스모피즘 남발, 떠다니는 3D 도형, 컨페티
- 맥락 없는 통계("10,000+"), 스톡 "다양한 팀" 사진, 목업 속 신호등 점 3개·태그 칩
- 기본 폰트(Inter 등)를 고민 없이 쓰기. 폰트는 톤에 맞게 고르고 @font-face로 로드
- 카드뉴스 쪽 번호("1 / 6")

## 코드
- 뻔한 걸 설명하는 주석, 일어날 수 없는 경우까지 막는 예외 처리, 한 번 쓰는 추상화·래퍼, 안 쓰는 변수·import, 요청 안 한 기능 추가
