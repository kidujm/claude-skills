# slop-check

판정 기준 목록은 `references/slop-list.md`. 이 스킬은 그 목록을 빠짐없이 적용하는 절차다.

필요: Python 3 (글 검사). 디자인 검사(5번)는 html 캡처에 Playwright, mp4 첫 프레임에 ffmpeg가 있으면 쓴다. 없으면 png만 직접 열어 본다.

## 1. 대상 확정
- 검사할 파일 경로를 정한다. 대화 속 텍스트면 임시 파일로 저장해 검사한다.
- 종류 판별: 글(md·txt·메일·본문) / 디자인(png·mp4·html·pptx) / 둘 다.

## 2. 기계 검사 (글)
`scan.py`는 이 SKILL.md와 같은 폴더에 있다. 설치 위치에 맞춰 경로를 넣는다.
```bash
python3 <이 스킬 폴더>/scan.py <파일>
```
- 엠대시, 장식 기호, 금지 어휘, 번역투, 순우리말 교체 후보 등 걸린 줄을 줄번호와 함께 출력한다.
- 걸린 줄은 고친다(순우리말 항목은 3-1 기준으로 판단). 0건이 될 때까지 다시 돌린다.

## 3. 눈 검사 (글)
기계로 못 잡는 것을 문장마다 본다.
- `references/slop-list.md`의 구조 버릇·부풀리기·기교 항목
- 출처 없는 일반론, 지어낸 숫자. 근거 없는 문장은 근거를 찾거나 지운다(지어내지 않는다)
- 한국어 문장 규칙(아래 3-1)
- 같은 명사 한/영 혼용 금지
- 남이 볼 문서에 작성 메모·"~용"·"~기준입니다"·상대 날짜("오늘", "내일") 금지
- "빼도 뜻이 그대로인가?" 그대로면 뺀다

## 3-1. 한국어 문장 규칙
순우리말 표현은 자제하고 한자어·외래어를 우선 쓴다.
- 바꾸는 예: 바로잡다: 수정하다, 알맞다: 적합하다, 갈래: 유형, 틀: 템플릿·양식, 솜씨: 역량, 쓰임새: 용도, 뒷받침: 근거, 살펴보다: 검토하다, 알아보다: 조사하다, 견주다: 비교하다, 꼼꼼히: 면밀히, 손쉽게: 간편하게, 길잡이: 가이드
- scan.py의 [순우리말] 항목은 교체 후보다. 문맥상 한자어가 어색하거나 뜻이 흐려지면 그대로 둔다(억지 치환 금지).
- 한자어를 쓰더라도 번역투("~를 통해", "~에 의해", "~함에 있어", "~되어지다")는 계속 금지.
- 윤문 도구가 순우리말로 되돌리면 이 규칙이 우선한다.

## 4. 가독성 검사
- 줄글 문단 대신 굵은 항목명 + 짧은 하위 불릿
- 한 문장 40자 넘으면 나눌지 본다
- 결론이 맨 위에 있는가, 크기·배치로 중요한 것이 먼저 보이는가

## 5. 디자인 검사
결과물을 직접 렌더해서 본다(png는 열어 보기, html은 Playwright 캡처, mp4는 `ffmpeg -frames:v 1`로 첫 프레임).
- `references/slop-list.md` 디자인 항목
- 글자 잘림·겹침, 첫 프레임 빈 판

## 6. 한국어 윤문을 거쳤다면
윤문 뒤 2번 기계 검사를 한 번 더 돌린다(윤문이 기호를 다시 넣는 경우가 있음).

## 7. 보고
- 고친 항목 수와 대표 예 2~3개만. 전체 diff 나열 금지
- 근거가 없어 지운 문장이 있으면 따로 알린다
